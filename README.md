ぽぽちゃんVOICEVOX読み上げBOT
VOICEVOX を使った Discord 読み上げ Bot です。

このBotは VOICEVOX の公式のものではありません。
VOICEVOX公式・各キャラクターの権利者とは関係ありません。

機能
テキストチャンネルの発言をボイスチャンネルで読み上げ
入室・退出の読み上げ(「〇〇さんが入室しました」)
リンクは「リンク省略」、30文字を超えたら「以下省略」
ユーザーごとの辞書(/dic_add)と読み上げ速度(/speed)
誰かがVCに入ると自動参加(/auto_on)、誰もいなくなって90秒で自動退出
複数サーバー対応

コマンド
| コマンド | 内容 | 権限 |
|---|---|---|
| /join /leave | 参加・退出 | 誰でも(/leave は同じVCの人) |
| /auto_on /auto_off | 自動参加の切替(実行したチャンネルを読み上げ) | サーバー管理 |
| /chara | 読み上げキャラ変更 | 誰でも |
| /speed | 自分の読み上げ速度 | 誰でも |
| /pitch | 読み上げの高さ(サーバー共通) | サーバー管理 |
| /dic_add /dic_remove /dic_list | 自分用の辞書 | 誰でも |

読み上げ内容の取り扱い
このBotは、読み上げる文章を保存・ログ出力・外部送信しません。
文章は音声を作るためにメモリ上で一時的に扱い、ローカルのVOICEVOXエンジンに
渡したあと破棄します。このコードでは、運営者が読み上げた内容を見ることは
できません。

保存するもの: サーバーごとの設定(キャラクター、ピッチ、自動参加の
チャンネル)、ユーザーごとの設定(読み上げ速度、辞書の登録内容)。
辞書に登録した単語と読みは、運営者から見えます。
保存しないもの: 読み上げたメッセージの内容。
BotはDiscordからメッセージ内容を受信できる権限(Message Content Intent)を
使いますが、読み上げ先に設定したチャンネル以外のメッセージは処理しません。

外部への通信
読み上げ: ローカルのVOICEVOXエンジン(既定は 127.0.0.1)にのみ、文章を送ります。
任意機能(運営者が設定したときのみ動作。未設定なら何も送りません):
運営者向け通知: 起動・エンジン停止/復旧・エラー名を、運営者の非公開
チャンネルにWebhookで通知します。メッセージ内容は含みません。
死活監視: 60秒ごとに、運営者が設定したURLへ稼働状況を送ります。
/status: 運営者だけが、参加中のサーバー名などを確認できます。
